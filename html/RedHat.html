Red Hat Courses & Learning Path

Red Hat provides industry-leading open source technologies and training in Linux, automation, containers, cloud, and application development, empowering organizations to build, innovate, and grow.

Our Red Hat training helps learners build practical skills, prepare for industry-recognized certifications, and advance their career opportunities with real-world enterprise technologies.

Your Red Hat learning journey

Build Your Skills with Red Hat

Follow a structured learning path designed to take you from foundational concepts to advanced skills with hands-on training and real-world applications.

  1. 01

    Getting Started with Linux Fundamentals (RH104)

    Introduces Linux concepts and basic Linux tools for beginners with little or no prior Linux experience.

  2. 02

    Red Hat System Administration I (RH124)

    Foundational Red Hat Enterprise Linux administration including CLI, files, users, services, networking, remote access, software management, and basic security.

  3. 03

    Red Hat System Administration II (RH134)

    Advanced Linux administration including installation, storage, file systems, SELinux, services, boot, troubleshooting, tuning, shell scripting, and containers.

  4. 04

    Red Hat System Administration III – Linux Automation (RH294)

    Linux automation with Red Hat Ansible Automation Platform, inventories, playbooks, roles, and reusable automation.

  5. 05

    Red Hat Application Development I – Programming in Java EE (AD183)

    Enterprise Java development including EJB, JPA, REST, CDI, messaging, and security.

  6. 06

    Red Hat OpenStack Administration I (CL110)

    Core operations for Red Hat OpenStack private cloud including projects, resources, privileges, networking, storage, monitoring, and troubleshooting.

  7. 07

    Introduction to OpenShift Applications (DO101)

    Application deployment, scaling, and troubleshooting on OpenShift.

  8. 08

    Red Hat OpenShift Administration I: Containers & Kubernetes (DO180)

    Deploy, manage, and troubleshoot containerized applications as Kubernetes workloads on OpenShift clusters.

  9. 09

    Red Hat OpenShift Development I – Introduction to Containers with Podman (DO188)

    Build, run, and manage containers using Podman and OpenShift, including images, networking, storage, and multi-container apps.

  10. 10

    Python Programming with Red Hat (AD141)

    Beginner Python programming covering syntax, control flow, functions, data structures, files, JSON, regular expressions, debugging, modules, and libraries.
