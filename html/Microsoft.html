Your Microsoft learning journey

Build Your Skills with Microsoft

Follow a structured learning path designed to take you from foundational concepts to advanced skills with hands-on training and real-world applications.

  1. 01

    Azure Fundamentals

    Provides foundational knowledge of cloud computing and Microsoft Azure, including core Azure services, architecture, management, and governance.

  2. 02

    Azure AI Fundamentals

    Introduces the fundamentals of artificial intelligence and machine learning on Azure, including common AI workloads and the Azure services used to implement them.

  3. 03

    Azure Data Fundamentals

    Introduces core data concepts and Azure data services, including relational and non-relational data, big data, and analytics workloads.

  4. 04

    Azure Security Engineer Associate

    Develops skills for implementing security controls and protecting Azure environments, including identity, security operations, data protection, and infrastructure security.

  5. 05

    Dynamics 365 Fundamentals (ERP)

    Provides foundational knowledge of Dynamics 365 ERP capabilities, with a focus on optimizing finance and operations functions and understanding how Dynamics 365 integrates with other technologies.

  6. 06

    Identity and Access Administrator Associate

    Develops skills in managing identities and access using Microsoft Entra ID, including authentication, authorization, access management, and identity security.

  7. 07

    Information Protection and Compliance Administrator Associate

    Covers the skills needed to protect organizational information and manage compliance using Microsoft security and compliance solutions, including Microsoft Purview.

  8. 08

    Microsoft 365 Fundamentals

    Provides foundational knowledge of Microsoft 365 services and capabilities, including Office applications, Teams, Viva, collaboration, productivity, and cloud-based work environments.

  9. 09

    Power Platform Fundamentals

    Introduces Microsoft Power Platform and its capabilities for analyzing data, building applications, automating processes, and creating AI-powered solutions using low-code/no-code tools.

  10. 10

    Security, Compliance, and Identity Fundamentals

    Introduces foundational concepts in security, compliance, and identity across Microsoft Azure and Microsoft 365, including Zero Trust, Microsoft Entra, security solutions, and Microsoft Purview.
